# CV Vizor — играбельное резюме «Экспедиция» для Vizor Games (гибрид 1+4)

## Контекст
Отклик на вакансию **Game Designer (Middle, remote)** в Vizor Games: сквозная разработка фич (гипотеза → дизайн → внедрение → оценка), casual F2P, live-ops/экономика. Концепт: карта-экспедиция в духе Klondike Adventures + живой тюнер лайвопс-события. Канон серии: один HTML, 0 сетевых запросов, «Сразу к резюме», PDF, тач, честный блок «чего у меня пока нет».

## Решения (подтверждены пользователем)
- **Арт:** бесплатные паки CraftPix (зимний топ-даун тайлсет + казуальный GUI) + код-арт (снег, северное сияние); условия free-лицензии — в README
- **Языки:** RU/EN, переключатель на титуле
- **PDF:** текущий `Yaroslav_Kukar_Game_Designer.pdf` из cv-gametech; кнопка в шапке и в контактах по образцу cv-gametech
- **Сборка:** паттерн cv-saber — `src/` + `build.js` → единый `index.html` (~1.5–2 МБ, PixiJS 8 инлайн, шрифты base64)
- **Контент:** всё портфолио подаётся как гейм-дизайн проекты под язык вакансии
- **Git:** коммиты по вехам в ходе разработки, пуш в GitHub, публикация на GitHub Pages

## GDD-документ (первый артефакт, коммит №1)
`GDD.md` в репо: концепция и сеттинг, core loop, схема экранов + вайрфрейм-скетчи, карта контента (станции/заказы/факты), баланс (энергия, награды, тюнер с формулами и проверками), метрики успеха (путь до PDF ≤ 60 сек, вес ≤ 2 МБ, 0 запросов), риски. GDD структурирован «под передачу в команду» — сам демонстрирует навык документации из вакансии.

## Подача под вакансию (как звучит каждый факт)
- Серия играбельных резюме → **«14 играбельных мини-игр под ДНК конкретных студий: тактика, ферма, босс-файт с баланс-инспектором, экономика внимания… Каждая: механики → баланс → RU/EN → релиз одним файлом»** = доказательство сквозной разработки
- Playable-ads (SDK MRAID + Splash Kitty 684 КБ + Mob Rush 472 КБ) → **«понимание UA-воронки F2P: каноны playable, ноль сетевых запросов»** — козырь к UA-фокусу Vizor
- Тюнер события → **«рабочий инструмент проектирования live-ops: гипотеза → расчёт когорт → вердикт»** = первая строка обязанностей
- «Королевства Эридора» → **«итеративный баланс после 15+ плейтест-сессий, цикл схож с анализом live-ops после релиза»**
- EchoLoop → **«прототип на стеке студии: Unity 6 + URP, левел-дизайн 8 уровней»**

## Гейм-дизайн: core loop
Титул → Карта: расчисти станции (получи факты) → Заказы: собери факты в заказ (открой раздел резюме) → заказ «Live-ops» открывает Тюнер → Лист кандидата → PDF/контакты. Путь до PDF ≤ 60 сек. Энергия — флейвор (восстановление ~2 сек, не блокирует). Пасхалки: 3 золотых самородка.

**Экраны:** Титул · Карта экспедиции · Тюнер · Лист кандидата · Отчёт экспедиции.

**Станции (7):** «Концепт-док» (GDD градостратегии) · «Королевства Эридора» (варгейм, 15+ плейтестов) · «Playable-цех» (SDK + 2 ролика) · «EchoLoop» (Unity 6, 8 уровней) · «Гавань мини-игр» (серия играбельных проектов, карточки-жанры) · «Баланс-мастерская» (тюнер, вероятности) · «Форт Vizor» (финал после всех заказов).

**Заказы = пункты вакансии:** «Сквозная фича», «Live-ops событие» (→ Тюнер), «Экономика», «Playable для UA», «Unity-прототип».

**Тюнер:** слайдеры (длительность, энергия/кирки, награда, затухание, доля цели) → кривые 3 когорт → вердикт по 5 проверкам; формулы в браузере, как в cv-gametech.

## Визуальная система (анти-«ИИ-дизайн»)
Ассеты CraftPix + код-арт; 6 токенов (снег/хвоя/брусника/золото/дерево/небо); 9-slice панели из GUI-пака; 2 OFL-шрифта base64, кернинг; авторские easing; эмодзи в UI запрещены.

4. Если `gh` не аутентифицирован — попрошу тебя один раз выполнить `gh auth login` (или дам готовые команды)
